# CycloneDX 1.6 schemas

Source: https://github.com/CycloneDX/specification/tree/55343ba19dee1785acf1ce9191540d5fd7b590db/schema

The three JSON schema documents and LICENSE are copied from this fixed official source. Validation uses only these local schema resources; no network schema resolution is permitted. The original copyright and Apache 2.0 notices are retained.

The SPDX identifier enumeration is updated from official source commit 6470e34ef83f915868ece48934cff52e10c9eb49. This permits current SPDX identifiers, including SMAIL-GPL, without dropping or rewriting observed licenses. The CycloneDX 1.6 document schema and JSF schema remain from the stated 1.6 source.
